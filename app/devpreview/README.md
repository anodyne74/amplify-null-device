# devpreview

Operator Placement, Pickup and Unload against fixture Routes, no sign-in or backend: run `NEXT_PUBLIC_DEVPREVIEW=1 npm run dev` and open `/devpreview/placement`, `/devpreview/pickup` or `/devpreview/unload` (the links at the top switch fixtures). Without the flag each page renders "This page could not be found". Fixtures live in `lib/devFixtures.ts`.
