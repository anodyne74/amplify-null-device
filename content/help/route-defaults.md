Your Route Defaults apply to every new Route we set up for you. We can still change them on any single Route.

## What you can set

- **Standing instructions**: instructions for every Route, such as gate codes or where to put signs.
- **Default signs per Stop**: how many signs go at each Property.
- **Standing sign collection day**: the weekday you usually want your signs collected. We'll plan sign collection for the next one after your signs go up. Choose **No preference** to have them collected the day after they go up. Changing it never moves a Route we've already set up.

Select **Save Route Defaults** when you're done. Changes apply from the next Route.

If we've switched on the Missing Signs Report for you, a switch here turns that email on or off. Once a Route is finished, it lists each Property where signs went missing. It's only sent when some are.

## Agents

Agents on this account lists the agent codes we use to label each Stop. To change them, email [{{supportEmail}}](mailto:{{supportEmail}}).

For instructions about one Route only, add a special instruction on that Route. See [Follow a Route](/customer/help/follow-a-route).
